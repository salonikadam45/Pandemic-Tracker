
## ✨ Key Features

###  R Shiny Dashboard & Forecasting Engine

* ** Automated Data Pipeline**: Fetches, cleans, and structures live global time-series data dynamically upon startup.


* **Epidemiological Trends**: Visualizes daily confirmed cases, recoveries, and deaths smoothed through a 7-day moving average.


* ** Clinical Outcome Analysis**: Tracks critical metrics such as Case Fatality Rates (CFR) and recovery ratios over time.


* ** Predictive Modeling**: Generates automated ARIMA-based time-series projections equipped with customizable confidence intervals.



###  Jupyter Notebook (`.ipynb`) Analytical Workflow

* ** Exploratory Data Analysis (EDA)**: Step-by-step data inspection, missing value handling, and structural data profiling.
* ** Geospatial & Trend Visualization**: Interactive plotting scripts mapping virus spread across regions and administrative boundaries.
* ** Prototyping & Modeling**: Sandbox environment for testing statistical transformations, data aggregations, and preliminary machine learning models before production deployment.

##  Tech Stack & Dependencies

* **Dashboard & App Framework**: R, `shiny`, `bslib`

* **Data Wrangling & Analysis**: `tidyverse`, `lubridate`, `zoo`, Python (`pandas`, `numpy`)


* **Visualization**: `ggplot2`, `plotly`, Python (`matplotlib`, `seaborn`)


* **Time-Series & Forecasting**: `tseries`, `forecast`
